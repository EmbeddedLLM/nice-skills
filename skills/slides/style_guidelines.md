# Slide design

Follow the user's template and purpose. Build a coherent composition with a clear title, deliberate alignment, readable type, and enough space to separate ideas. Avoid treating every slide as a dashboard of repeated cards.

Use a native chart for a supported quantitative comparison, a table for shared attributes, and a diagram for relationships or sequence. Keep the requested evidence editable. Supplied images and locally constructed SVG/shapes are valid; no image-generation service is required.

Match template sizes when adapting a deck. Without a template, start around 32-point slide titles and 18-point body text, then judge actual viewing size. If a layout overflows, simplify copy, split content within the authorized slide count, or choose a better arrangement before reducing type.

Use color for consistent meaning and adequate contrast. Check captions, legends, chart units, axis labels, and citation text. Preserve image proportions and use intentional crops.

Render all slides, inspect the complete sequence and individual slides, correct defects, and re-render affected output. A successful PPTX export alone cannot establish legibility or native application compatibility.
