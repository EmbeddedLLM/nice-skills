# Bundled presentation templates

The six-template pack replaces the old slide-template collection. All files live inside this skill at [slide_templates](../slide_templates/).

| File stem                | Slides | Use                                                |
| ------------------------ | ------ | -------------------------------------------------- |
| `Academic_05`            | 15     | Research context, methods, findings, discussion    |
| `Brand_Design_05`        | 15     | Brand direction, identity, visual applications     |
| `Consulting_Proposal_05` | 14     | Problem, approach, scope, delivery, proposal       |
| `Market_Research_02`     | 15     | Market landscape, segments, evidence, implications |
| `Pitch_Deck_02`          | 14     | Problem, solution, market, model, team, ask        |
| `Project_Kick-off_03`    | 14     | Objectives, scope, plan, roles, risks              |

`PPTX/<stem>.pptx` contains editable example decks. `POTX/<stem>.potx` contains the corresponding reusable template files. Start from PPTX for programmatic edits; use POTX in an application that supports template instantiation. Do not merely rename POTX to PPTX without updating the package content type.

Inspect [Template_Overview.png](../slide_templates/Template_Overview.png) for cover comparison and [Preview_All_Templates.pdf](../slide_templates/Preview_All_Templates.pdf) for all 87 slides. Read [START_HERE.txt](../slide_templates/START_HERE.txt) and each slide's notes.

The canvas is 16:9, 13⅓ × 7½ inches. Tables and charts are native objects; charts include example workbooks. Replace sample values, units, labels, schedules, responsibilities, and bracketed fields. Copy a sample slide to retain its richer arrangement; generic layout placeholders may not include every sample object. Remove or hide drafting style-guide slides before sharing.

DejaVu Sans and Serif fonts are supplied in `Fonts/` with [their license](../slide_templates/Fonts/LICENSE_DEJAVU.txt). They are separate files, not embedded fonts. Install locally through the host-approved mechanism or disclose a substitute and recheck wrapping.

Keep [template reuse permission](../slide_templates/Template_Reuse_Permission.txt) and font notices with redistribution. The pack permits reuse of its newly authored template material; assets later added by a user retain their own rights.
