How the added Office colours were chosen

Apply the palette

PowerPoint

  1. In desktop PowerPoint, open Design → Variants → Colors → Customize Colors.
  2. Enter the 12 values shown under PowerPoint colours, then save the set with the palette name.
  3. Set the slide background and text to the values shown above. For a dark palette, explicitly select the dark background.

The XML download is the same complete colour set. To use it as a local preset, first save a uniquely named custom colour set in PowerPoint and locate that XML file on your computer. Add the downloaded XML to that active Theme Colors folder, then restart PowerPoint. Folder locations vary by installation.

Method and compatibility notes
Fifty community-inspired palettes replace the earlier software-theme selection. Exact reference colours are kept separately from the applied UI roles. Added neutrals, hover shades and Office companions are adaptations.
Contrast checks use the final 8-bit HEX values. Normal text pairings meet at least 4.5:1, and the dedicated interactive borders and focus colours meet at least 3:1 against the specified backgrounds. These checks concern those exact colour pairs. Page structure, focus behaviour, chart interpretation and other accessibility requirements also depend on the finished design.
The colour XML files have been checked for structure and exact values. They have not been opened in native Microsoft PowerPoint in this environment. The manual 12-slot entry method remains available if your installation does not expose the preset folder.
These are colour schemes. They do not include slide layouts, font files, photographs or third-party page templates.

Pastels for fills, ink for words
Use Dark ink #202334 for text on every pastel card. It measures at least 12.01:1 against these four accent fills. White text on a dark-ink primary button measures 15.54:1.
The selected navigation item adds a dark left edge and bold text, so its meaning does not depend on the lavender fill alone.
Keep the grey in the right place
Muted grey #676976 works as secondary text on white (5.44:1) and warm off-white (5.17:1). It falls below 4.5:1 on lavender and peach, so those cards use dark ink.
Soft grey #E7E6E2 is a decorative border or divider. The example uses dark ink for the input boundary and keyboard-focus outline. Text-contrast reference.
