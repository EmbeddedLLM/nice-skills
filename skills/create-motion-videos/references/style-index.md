# Complete style selector

Includes every one of the 51 main Lemo styles plus one added twoclipping family with two variants. The separate [OPUSCAR 98 collection](opuscar98-index.md) contains 98 cinematic reference prompts, not 98 additional full engines.

Pinned source: [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar/tree/b5e8ef93930b6d828f352055a689320f138237b1). Read one chosen guide in full. Use each style's frame rate, material and camera rules.

## Quick selection

Choose Whiteboard for mechanisms, Swiss for structured graphics, Data Storytelling for measured comparisons, UI Morph for compact interaction loops, and Product Launch for a light interface-led promo. For a real scan or dataset, match one of the Evidence Films. Explore the full collection for illustration, print, tradition, games and 3D. These are selection recommendations, not restrictions.

## Added twoclipping family

Read [the original skill adaptation](twoclipping.md), then select one variant. This family is independent of Lemo and is not endorsed by twoclipping.

| Selector                     | Use                                                                                     |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| `twoclipping:ui-morph`       | A short continuous sequence of functional UI states; optional seamless loop.            |
| `twoclipping:product-launch` | A light product story with causal UI transitions and optional supplied imagery/footage. |

Nearest Lemo styles overlap in some features but differ in their invariants; see [the overlap assessment](twoclipping-overlap.md).

## Find and load

Use `scripts/styles.py list --query "watercolor"`, `list --query "水彩"`, `show lemo:whiteboard`, or `show twoclipping:ui-morph`. A broad name matching two variants returns both IDs rather than choosing silently.

## Additional edit and documentary styles (2026-10-26)

These eight additions bundle style guides and metadata. Author a new film with the existing browser starter; their upstream demo footage, sample factual stories, and provider-specific scripts are not bundled.

- [Constructivist Montage](../assets/lemo/styles/kino-montage/STYLE.md): Industry histories, Milestones, Collective effort.
- [Broadcast News Package](../assets/lemo/styles/news-package/STYLE.md): News round-ups, Bulletins, Market updates.
- [1920s Newsreel](../assets/lemo/styles/newsreel/STYLE.md): History stories, Fads & eras, Anniversaries.
- [Sports Telestrator](../assets/lemo/styles/telestrator/STYLE.md): Sports analysis, Match recaps, Coaching.
