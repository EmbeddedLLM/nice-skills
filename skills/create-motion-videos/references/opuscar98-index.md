# OPUSCAR 98: cinematic reference index

All 98 original bilingual reusable prompts are bundled in [opuscar98_styles.json](../assets/lemo/styleboard/opuscar98_styles.json). This collection is separate from the 51 main styles. It contains 77 2D, 4 2.5D and 17 3D references.

Load just the chosen entry with `python3 scripts/styles.py show opuscar:001` (add `--language zh` for Chinese). Search film names with `scripts/styles.py list --collection opuscar --query "<title>"`. The style is reusable; the reference film's story, shot order and compilation timings are not a new project brief.
