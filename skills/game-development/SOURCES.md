# Sources and notices

Browse the [material catalogue](references/material-catalogue.json) for local paths, uses, source links, revisions, and recorded licenses. Unresolved provenance fields are written as `"Unknown"`; the catalogue does not replace the notices and scope below.

Adapted from [awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/tree/184b72be02884f782a0058f2eeae2ce4277453e4), revision `184b72be02884f782a0058f2eeae2ce4277453e4`, retrieved 2026-10-26. Apache-2.0; retained [LICENSE.txt](LICENSE.txt) and [NOTICE.txt](NOTICE.txt). The bundled Ebitengine starter retains its Go-Fonts notice.

The 76 specialized guides and their local references, examples, and nine helpers are bundled under `library/`. The new entry point routes by the existing engine and task without installing a router plugin or choosing an engine silently. Paths in each guide resolve relative to that guide's directory. Named companion guides resolve through the index. Host permissions, user choices, and project rules take precedence over upstream fixed defaults or publishing examples. Publishing, account creation, paid generation, and global installation require the user's relevant authorization.

Excluded root/category README files about upstream authoring policy. Local modifications: pinned the raster helper's Pillow dependency to the repository-tested version; adapted upstream regression paths and added test-intention docstrings; applied repository Markdown/JSON formatting. Engine-specific APIs and templates are reference material, not evidence that an engine build ran here. No engine, third-party art pack, platform SDK, or store credentials are bundled. Small upstream synthetic starter fixtures remain included.
