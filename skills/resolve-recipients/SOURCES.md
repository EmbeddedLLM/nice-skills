# Sources and notices

Browse the [material catalogue](references/material-catalogue.json) for local paths, uses, source links, revisions, and recorded licenses. Unresolved provenance fields are written as `"Unknown"`; the catalogue does not replace the notices and scope below.

This package reimplements the entry-point workflow from the user-supplied repository snapshots `resolve-recipients`. Supporting tools and selected references were retained where useful; their provenance is the supplied snapshot, not a new upstream retrieval. The installed package is self-contained and does not read the original snapshots.

The supplied legacy snapshot did not include a package-level third-party license notice. This record does not assert a new license for inherited material. Newly written repository contributions follow the repository MIT license; separately attributed schema, library, and asset terms remain applicable.
